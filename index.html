Demographic Causality Diagnostic

Diagnostic rule: demographic probabilities remain unchanged. This build instruments the causal funnel instead of fixing it: reproductive-age exposure → partnership opportunity → viable partner pool → partnership formation → partnered reproductive years → family-expansion opportunity → child decision → birth, plus migration and mortality.

Each diagnostic world runs 1926→2426. The 1926→2026 funnel is captured separately because that first century already exposed the bias. A 1,000-world acceptance run belongs after the causal defect is corrected; there is no value in spending several minutes proving the current model fails 1,000 times.
